## Recursos subidos al Portal de Datos Abiertos

Este proyecto consta de un jupyter notebook que solicita todos los recursos disponibles mediante la api del portal de datos abiertos y genera un archivo csv a partir de elos.

Cada fila representa un recurso subido e inlcluye la fecha de creación, la fecha de actualización y la semana del año al que pertenecen (obtenida mediante la función isoCalendar).

El archivo se actualiza todos los días de manera automática.
