## Recursos subidos al Portal de Datos Abiertos

Este proyecto genera un archivo csv con todos los recursos que se pueden obtener mediante la api del portal de datos abiertos. Cada fila representa un recurso subido e inlcluye la fecha de creación y la fecha de actualización; además se le agregó la semana del año al que pertenecen usando la función isoCalendar.

El archivo se actualiza todos los días de manera automática.
